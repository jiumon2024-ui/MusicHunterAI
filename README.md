# Music Hunter AI · версия 0.9.0

## Главное изменение: единый поиск по интернету

- Введи запрос на русском или английском и нажми **«Исследовать»**. Кнопка «Веб» удалена.
- Приложение выполняет две части одного поиска: ищет аудиофайлы в Openverse, Wikimedia Commons и Internet Archive и отдельно веб-страницы через публичную RSS-выдачу Bing.
- Для распространённых музыкальных жанров агент попробует вариант поискового запроса на другом языке. Точное автоматическое машинное переводирование произвольного текста не предусмотрено.
- На открытой странице встроенный браузер обнаруживает стандартные HTML5-аудио и прямые ссылки. Можно запустить ограниченное исследование сайта с учётом robots.txt.
- Прямые MP3/OGG/FLAC/WAV/M4A-ссылки, если веб-поиск их вернул, добавляются в список аудио, но **лицензия не считается подтверждённой**.
- Таймкод показывается у каждой аудиозаписи, если каталог сообщил длительность. Во время воспроизведения показывается текущая позиция. Без данных — «—:—».
- Фоновая проверка новых версий через GitHub Releases (ориентировочно раз в 12 ч) и загрузка по интернету без USB при настроенном репозитории. Android попросит подтвердить установку.

**Границы:** это бесплатный агент на правилах, а не универсальная нейросеть. RSS выдача — неофициальная точка поиска, может стать недоступной, блокироваться или возвращать неполные результаты. Нельзя обещать «весь интернет»: поисковые движки индексируют не все страницы. Открытие страницы не означает право на скачивание/прослушивание защищённой музыки; DRM, подписки и платные доступы не обходятся.

**Как установить поверх существующей версии 0.7:**
1. Сохрани резервную копию папки проекта.
2. Открой ZIP `MusicHunterAI_обновление_0.7_до_0.9.zip` и распакуй папку `КОПИРОВАТЬ_В_СУЩЕСТВУЮЩИЙ_MusicHunterAI`.
3. Скопируй её содержимое внутрь существующей папки проекта `MusicHunterAI`, с заменой совпадающих файлов. Не копируй саму внешнюю папку.
4. Открой уже существующий проект в АС, нажми `Sync Now` и `Build → Generate App Bundles or APKs → Generate APKs`.
5. Проверь поисковые запросы на русском и английском; для автообновлений сначала настрой GitHub и release-подпись (см. `НАСТРОЙКА_АВТООБНОВЛЕНИЙ.md`).

**Файлы полной версии:** ZIP `MusicHunterAI_AndroidStudio_Windows_0.9.zip` — полноценный проект для открытия через АС.

**Проверки:** проверены XML-файлы, структура и синтаксис модуля веб-поиска компилятором Kotlin со вспомогательными заглушками. Полная сборка Android APK и работа RSS на реальном телефоне в данной среде не проверены.

# Music Hunter AI · Android Studio project

Русскоязычный прототип музыкального поискового Android-приложения. Без платной подписки и без собственного сервера.

## Быстрый запуск (Windows)

1. Распакуйте ZIP в папку `MusicHunterAI`.
2. **Один раз:** откройте `ПОДГОТОВИТЬ_GRADLE.cmd`. Он скачает официальный Gradle Wrapper JAR версии 8.11.1 и проверит SHA-256 из [официальных контрольных сумм Gradle](https://gradle.org/release-checksums/). Прямое включение бинарника в ZIP недоступно в нашей среде.
3. Откройте папку `MusicHunterAI` в Android Studio через **Open**.
4. Дождитесь **Gradle Sync**. При запросе установите Android SDK Platform 36.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Итоговый debug APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Должны быть подключены интернет и Android SDK 36, JDK 17+ (Android Studio содержит встроенный JDK).

## Реализовано

- Русскоязычный интерфейс с неоновой стилистикой и фирменной иконкой.
- Панель здоровья каждого каталога: HTTP 429, Retry-After, сохранение таймера после перезапуска, автоматическая повторная проверка при открытом приложении.
- Экономный поиск: дополнительный вариант запроса Openverse отправляется, только когда первый дал менее пяти результатов; каталог Internet Archive проверяет до четырёх записей.
- Дисковый кеш ответов на 12 часов (до 240 ответов / 12 МБ), повторные поиски не расходуют сетевые запросы там, где данные уже сохранены. При лимите источника приложение читает ранее кешированные ответы.
- В финале поиска показывает количество ответов из кеша и сетевых обращений (это НЕ остаток квоты на сервере).
- Поисковый агент без LLM, генерирует варианты запросов и агрегирует аудио через Openverse, Wikimedia Commons и Internet Archive.
- Встроенный браузер для посещения страниц, выделения открытых HTML5-аудиоссылок и ограниченного обхода (до 12 страниц, один домен, robots.txt).
- Media3 ExoPlayer: воспроизведение прямого HTTPS-аудио, пауза, перемотка и время.
- Загрузка через Android DownloadManager (с подтверждением прав) в `Music/MusicHunterAI`.
- Минимум Android 6.0 (API 23), target 35.

## Ограничения

Это **не** большая нейросеть, которая может открыть любой сайт и скачать любую музыку. Поисковый агент — локальный, основанный на правилах. Популярные защищённые треки часто нельзя воспроизвести или сохранить; доступ регулируют сайты, лицензии и DRM. Скачивайте только файлы, на которые у вас есть право. Openverse и другие каталоги накладывают ограничения на частоту запросов и доступность файлов. Приложение не устанавливает лимит поисков, но не может гарантировать неограниченную доступность внешних API. Кеш хранится в временном хранилище Android и может очищаться системой. Результаты зависят от интернет-соединения.

В среде генерации отсутствовали Android SDK/Gradle и сетевой доступ для загрузки обёртки, поэтому проверены структура, исходники и XML, **не** фактическая компиляция. Если получаете ошибку Build — приложите её текст.

## Обработка данных
Запросы на поиск отправляются напрямую из телефона сторонним открытым каталогам. Ключи и платный сервер не используются; источники могут вести журналы запросов по своим правилам.
